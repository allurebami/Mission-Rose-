# Mission Rose V1

Mini-jeu web Octobre Rose soutenu par ellegagne.com.

## Fonctionnalités V1

- 5 niveaux de sensibilisation.
- 3 difficultés : facile, moyen, dur.
- Score par points avec multiplicateur selon la difficulté.
- Top 5 local dans le navigateur.
- Photo finale avec badge et score.
- Partage WhatsApp.
- Bouton de don pour soutenir 5 femmes dans le besoin.

## Lancer le jeu

Ouvrir `index.html` dans un navigateur moderne.

Pour tester avec un petit serveur local :

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## V2 recommandée

- Connecter Supabase pour un vrai classement public.
- Ajouter CinetPay, Flutterwave, Notch Pay ou PayDunya pour suivre les dons.
- Créer une page d'administration pour valider les bénéficiaires et publier le résumé de transparence.
- Ajouter les logos officiels des partenaires et un domaine dédié.
